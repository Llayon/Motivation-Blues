# Design System

## Direction

Light, calm, premium writing room. The interface should feel intentional and soft, with rewards as gentle rituals outside the writing flow.

## Visual Language

- Light glassmorphism panels.
- Soft gradients and aurora backgrounds.
- Dark ink typography on bright surfaces.
- Blue/mint/gold accents.
- Rounded, tactile controls.

## Typography

- Current implementation uses expressive serif headings and readable body text.
- Avoid generic SaaS visual tone.
- Avoid default-looking purple startup UI.

## Editor Rules

- The editor should feel distraction-free.
- Reward modals must not appear while typing.
- Autosave status should be visible but quiet.

## 3D Rules

- Figurines should feel like glossy collectible toys.
- Current procedural models are placeholders.
- Future GLTF assets should preserve original materials and textures.
- Lighting may enhance premium feel but should not distort asset identity.

## Mobile

- Editor must remain usable on small screens.
- Navigation may wrap, but writing area must stay readable.
