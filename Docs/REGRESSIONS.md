# Regression Log

Record fixed regressions here so future LLM sessions know which behaviors are fragile and which tests protect them.

| Date       | Regression                                                                 | Root Cause                                                                         | Fix                                                                                        | Guardrail                                                                                        |
| ---------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| 2026-06-01 | Local mode could disappear after reload when Supabase had no session       | Zustand persist hydration and Supabase session check raced during app boot         | Wait for persist hydration and preserve local profile when no cloud session exists         | `tests/e2e/local-writing-flow.spec.ts` local mode and autosave flows                             |
| 2026-06-01 | Banked post edits could behave like new bank events                        | Edit flow needed a separate update path from banking logic                         | Added `updateBankedPost` and editor target handling                                        | `tests/e2e/local-writing-flow.spec.ts` banked edit test                                          |
| 2026-06-01 | Opening another banked post could replace an unrelated autosave buffer     | Editor target loading did not make the conflict explicit enough                    | Added conflict UX for unrelated emergency buffers                                          | `tests/e2e/local-writing-flow.spec.ts` banked edit conflict test                                 |
| 2026-06-01 | Formatting selection E2E was flaky                                         | Test clicked before textarea selection state settled                               | Stabilized selection polling before using the formatting menu                              | `tests/e2e/local-writing-flow.spec.ts` formatting test                                           |
| 2026-06-02 | Startup could stay on "Подключаю облачный сезон..." when Supabase stalled  | Cloud hydration blocked the root UI without timeout or fail-open behavior          | Added bounded cloud timeout, background refreshes, stale-request guard, and AuthGate retry | `src/lib/cloudHydration.test.ts`, `tests/e2e/local-writing-flow.spec.ts` cloud fallback test     |

| 2026-06-02 | App could hang on Supabase loading screen during TMA integration           | Missing timeout in Telegram auth flow and race condition in pre-empted hydrations  | Added `withCloudTimeout` to TMA auth and refactored store hydration to be race-resilient   | `src/lib/cloudHydration.test.ts` and refined `hydrateFromSupabase` logic                         |

## Rule

- When fixing a regression, add or identify the test that would fail before the fix.
- If no automated test is practical, add a manual QA step and explain why automation is deferred.
